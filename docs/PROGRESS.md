## Notes

Decisions made along the way, newest last.

- 0.1: Fixed 320×180 resolution with whole-number zoom (not Phaser's FIT) so pixels never blur.
- 0.1: Text uses a built-in 5×7 bitmap font instead of browser text, which anti-aliased at small sizes.
- 0.2: Renamed `src/content/colours.ts` to `palette.ts` (export `PALETTE`) to match the rulebook.
- 0.2: Default controls changed to the rulebook set; jump is Space only (Up and W removed). Not wired up yet.
- 0.2: `images/` holds source files only; anything the game loads is copied into `public/assets/`. Debug overlays (F1/F3) may use inline strings.
- 0.3: Maps keep a shared external tileset (`.tsj`). Phaser can't read those, so LevelLoader loads the `.tsj` itself and embeds it before Phaser parses the map. Image paths are resolved like Tiled does.
- 0.3: The placeholder tileset (PNG and `.tsj`) is generated by `npm run tiles` from one list in the script; colours come from `PALETTE.tiles`. Edit the script, not the `.tsj`.
- 0.3: Only the `Ground` layer collides. One-way tiles collide on their top face only (Phaser's tile faces); bodies sunk more than 16px into one gets no push (Arcade `tileBias`). Revisit with Bit's movement in 1.1.
- 0.3: Benches are one-way platforms, grill windows are solid (for walls on Ground), spikes carry `hazard` but do nothing yet.
- 0.3: Object types come from a registry (`src/systems/levelObjects.ts`); unknown types are skipped with a warning. `PlayerSpawn` is a marker for now and the camera starts centred on it.
- 0.3: Groundwork: `ActionKeys` input helper reading `controls.ts`, temporary `panLeft/Right/Up/Down` (arrows) and `debugPhysics` (F1) controls, `CAMERA_PAN_SPEED` in tuning, `START_LEVEL` in `src/config/levels.ts`. ESLint now knows Node globals for `scripts/`.
